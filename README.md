# StoreSketch

StoreSketch is a lightweight web-based canvas tool for working with store layouts and visual planning.

## Features

* Interactive canvas
* Grid and coordinate system
* Pan and zoom controls
* Mouse and touch support
* Responsive layout for desktop, tablet, and mobile
* Simple tools for navigating and editing the workspace

## Development

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```

## Deployment

This project can be deployed directly to **Vercel** from GitHub.
https://drawing-web-nu.vercel.app/

## Notes

* No backend is required.
* No confidential store blueprints or internal files are included in this repository.
* Only source code and non-sensitive assets should be committed to GitHub.
